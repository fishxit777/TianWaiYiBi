# V28 常見問答、法律中心與私人客服設計

日期：2026-08-30

## 目標

為天外盲策補上可完整查閱的常見問答、購買與服務條款、隱私聲明、數位內容與退款規則，以及天外一筆專屬的私人客服入口。資訊架構參考成熟官網的 FAQ／法律中心模式，但文案、視覺、信箱、表單與資料全部維持本專案獨立。

## 已確認範圍

1. 法定營運主體資料這一版先不阻擋；正式 NT$199 收款仍保持關閉。
2. 授權採非專屬實作使用：買家可自行評估、改寫概念並實作或商用，但不得複製、公開、散布或轉售交付的原文、圖像與版面，也不取得獨家、著作權讓與、專利或成果保證。
3. 退款以首次成功揭示完整內容為界；揭示前可申請取消，揭示後不受理單純反悔，但重複扣款、未交付、持續無法取用或交付重大不符等權利不受影響。
4. 不承諾無條件永久營運；改說明服務存續期間可重複取回，若終止服務將提前通知並提供合理取回安排。
5. 客服只處理付款、收信、開通、登入、退款、個資權利與消費申訴，不提供公開留言、聊天室、客服小幫手或客戶 LINE。

## 方案比較

### 採用：專屬外部表單＋專屬客服信箱

表單由天外一筆自己的帳戶建立，回覆只讓營運者查看；網站只提供外部表單連結與 `mailto`。優點是最接近已確認的萬語通資訊架構、不在應用程式重建訊息資料表、維護與資安面最小。缺點是第一次建立信箱與表單需要擁有者登入。

### 不採用：站內客服資料表

可完全客製並用管理員 LINE 通知，但會新增個資保存、垃圾訊息、後台工單、通知失敗與刪除週期，實質上讓 V26 退役的客戶訊息系統重新長回來。

### 不採用：只有客服信箱

工程最少，但缺少問題分類、防敏感資料提醒與一致的申訴欄位，不符合擁有者已確認的「信箱＋客服表單」。

## 資訊架構

- `/faq`：九題購買前常見問題，以原生 `details` 分類呈現。
- `/policies`：同頁三個可展開章節：購買與服務條款、隱私聲明、數位內容與退款規則。
- `/terms`、`/privacy`、`/refunds`：導向法律中心對應章節。
- `/support`：私人客服說明、受理範圍、安全提醒、專屬表單與客服信箱入口。
- 桌機主導覽加入「常見問答」「條款」；手機長導覽維持精簡，FAQ、條款與客服集中在頁尾。
- 結帳確認視窗連到法律中心，訂單保存新條款版本。

## 視覺

沿用 V22～V25 的明霄雲海、青玉、暖金、宣紙仙卷與既有 Q 版仙伴；不複製萬語通的黑綠科技風。FAQ 使用「問卷仙籤」，法律中心使用「三卷公約」，客服頁使用「月白傳書台」。文字全部維持 V19 正黑體，裝飾不遮擋正文；動畫只做展卷、雲霧與仙伴微動，並尊重 `prefers-reduced-motion`。

## 資料與安全

- 公開頁不輸出未設定的信箱或表單網址，也不沿用其他專案聯絡資料。
- 外部表單只收必要資訊：聯絡 Email、問題類型、公開封印名、訂單末段（若有）與問題說明。
- 表單明確禁止提交密碼、驗證碼、完整付款資料、Passkey、復原碼、Token 或私鑰。
- 官網不新增客服訊息資料表、客戶 LINE webhook、公開留言 API 或管理訊息佇列。
- 隱私聲明揭露交易、帳號安全與第一方匿名需求分析所需資料類別、目的、利用對象、保存原則及權利行使方式。

## 驗收標準

1. FAQ 與法律中心內容完整、可鍵盤操作且每頁有正確導覽；結帳可查閱當版條款。
2. 天外一筆專屬客服信箱與私人表單可從 `/support` 進入；未設定時不冒用其他專案資料，公開付款仍關閉。
3. 退役留言／聊天／客戶 LINE 路由仍為 404；全套測試、機密掃描、桌機與 390×844 Browser QA、正式部署與 main/origin 同步全部通過。
