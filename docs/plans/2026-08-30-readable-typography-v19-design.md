# V19 全站清晰字體設計

日期：2026-08-30

## 決策

保留所有 Logo 與品牌題字圖像，不再把書法字體套在可閱讀、可操作或需要快速掃描的文字上。前台、交易流程、客戶頁、管理登入、安全設定與營運後台統一使用繁體中文介面常見的正黑體系，依平台優先採用 Microsoft JhengHei UI、PingFang TC、Noto Sans TC 與 Heiti TC。

## 可讀性基準

- 公開頁正文桌機 18px、手機 17px，行高至少 1.7。
- 公開頁導覽與按鈕至少 15px，補充資訊至少 13px。
- 後台正文與操作元件 14px，資料表與狀態資訊至少 12px。
- 手機表單輸入維持 16px，避免 iOS 自動放大。
- 標題使用正常字體的粗細與尺寸建立層級，不再用毛筆字形。
- 訂單碼、復原碼等需要逐字辨識的資料可保留等寬字體；這不是品牌書法字。

## 實作方式

新增最後載入的 `static/v19.css` 作為單一可讀性層，覆蓋舊版本殘留的書法字與過小字級。舊 CSS 與自架字型檔暫時保留，避免一次刪除歷史資產造成不必要風險；公開 HTML 不再預載書法字型，因此一般訪客不會為未使用字型增加下載成本。

## 驗證

自動測試核對所有公開與管理模板載入 V19、公開頁不再預載書法字型、V19 同時覆蓋前後台。另以桌機與 390px 手機檢查首頁、盲策詳情、交易／登入頁、管理登入與後台主要工作區的 computed font、最小字級、水平溢位與 console。
