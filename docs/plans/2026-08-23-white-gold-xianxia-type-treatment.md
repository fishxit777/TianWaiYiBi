# 白玉月金立體修仙題字設計

日期：2026-08-23

## 唯一視覺基準

依使用者提供的仙俠小說封面題字，不再把需求簡化成「換一套毛筆字」。參考圖的完成感來自五個同時存在的層次：粗筆行書骨架、白玉與舊金雙色、深酒紅墨邊、向右下堆疊的金色厚度，以及貼近字腳的黑色投影。字面保留飛白與長收鋒，但輪廓必須清楚。

## 實作方案

- 正文維持自架正風毛筆 Regular，保留同一書法骨架與繁中字覆蓋。
- 題字由 Medium 提升為 Bold，讓 CSS 外框與立體層不會吃掉筆畫。
- 首頁與傳音頁的第一行使用白玉題字、第二行使用月金題字，對應參考圖上下兩層。
- 全站 H1／H2 使用完整白金立體層；H3、品牌字、導覽、按鈕、價格與卡片重點使用較輕的金石層，維持層級與可讀性。
- 文字仍是 HTML，不烘成圖片，因此商品名稱、後台內容、價格、SEO、複製與無障礙名稱都保持可更新。
- 內文不套厚外框，避免長文與小字黏成一片；但仍使用同系書法字體。
- 後台與本機工具不納入公開品牌題字規格。

## 驗收

- 首頁 Hero 必須一眼看出白玉／月金兩層與深色立體厚度。
- 桌機 1280 與手機 430 × 900 檢查首頁、商品、結帳、傳音。
- H1／H2 不得裁切、重疊或造成根頁面水平捲動。
- 正文、表單與按鈕仍需清晰可讀；兩套字型檔實際載入。
