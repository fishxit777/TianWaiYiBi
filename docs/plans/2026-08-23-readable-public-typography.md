# V14.1 公開站清晰字級修正

日期：2026-08-23

## 問題

V14 主視覺題字方向正確，但公開頁仍沿用大量 9–13px 的舊版卷標、導覽、分類、卡片說明與傳音提示。毛筆字形在這個尺寸下筆畫擠在一起，再加上灰階字體平滑，實際畫面顯得又小又糊。LOGO 下方 `TIANWAI YIBI STUDIO` 只有 9px，手機版更被直接隱藏。

## 設計決策

- 保留三張 V14 仙俠封面題字，不改造型與比例。
- 公開站正文基準提高到桌機 18px、手機 17px。
- 首屏與品牌理念等主要說明提高到桌機 19px。
- 導覽、卷標與按鈕提高到 13–15px，卡片中繼資料最低約 12.5–13px。
- LOGO 英文副標改用清楚的英文襯線體、桌機 12px；手機保留顯示並使用 10–10.5px。
- 公開站恢復瀏覽器原生字體平滑，減少細筆畫在 Windows／Chromium 上的灰霧感。
- 後台與開發工具不套用本次放大，避免營運介面密度被破壞。

## 驗收

- 首頁與傳音頁的 LOGO 英文副標可直接辨識。
- 正文、卡片摘要、篩選與傳音提示不需放大瀏覽器即可閱讀。
- 主視覺題字仍是唯一最強層級，文字放大不重新製造標題混亂。
- 桌機與 390px 手機無水平溢位。
- 公開流程與安全測試全部通過。
