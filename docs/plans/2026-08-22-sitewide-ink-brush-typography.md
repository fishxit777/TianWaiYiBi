# 全站墨韻毛筆字系更正

> 已於 2026-08-23 被 `2026-08-23-logo-aligned-calligraphy.md` 取代。此文件保留為歷史決策紀錄；莫大毛筆字體已從現行網站移除。

日期：2026-08-22

## 真正需求

使用者要的不是細手寫字，也不是只改傳音分頁；而是整個公開官網都採用接近「風雲」參考圖的厚重毛筆質感：有真實提按、筆鋒與飛白，同時保持螢幕縮放清楚。

## 採用方案

- 全部公開頁面共用莫大毛筆字體。
- 正文、導覽、按鈕與表單使用原筆 Regular。
- 主標、卡片標題與強調文字使用同系 Medium。
- WOFF2 自架並按公開網站字元子集化，不依賴訪客電腦字型。
- 禁用文字 glow 與 CSS 假描邊，避免縮放後邊緣發糊。
- 後台、隱藏 Logo 評估與本機 LINE 模擬器維持工具型排版，避免品牌調整干擾操作效率。

## 選字理由

莫大毛筆字體補齊臺灣教育部常用繁體字、調整臺灣標點位置，並以 SIL OFL 1.1 開放商用與改作。原筆保留真實墨韻，Medium 只用於大字，避免長文過粗黏連。

## 驗收範圍

- 首頁 `/`
- 六脈仙策 `/ideas/<slug>`
- 結帳 `/checkout/<slug>`
- 模擬付款 `/pay/mock/<token>`
- 專屬交付 `/orders/<token>`
- 公開訊息頁
- 傳音頁 `/transmission`

每一類頁面至少驗證桌機版；首頁、商品、結帳、傳音另驗證手機版、無水平溢位、字型實際載入與繁體缺字。
