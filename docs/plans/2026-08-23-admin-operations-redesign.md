# 天外一筆後台營運改版設計

## 目標

把目前「所有資料同頁攤開」的工程控制台，改成每天能快速判斷與處理工作的營運後台。核心順序是先看異常與待辦，再處理訂單、內容與客戶，最後才進入串接及安全技術資訊。

## 資訊架構

1. 今日總覽：四個核心 KPI、待處理事項、近七日營收、近三十日流量。
2. 交易訂單：訂單搜尋、狀態篩選、成交與待付款清單。
3. 仙策內容：全站價格、六脈上架狀態、內容編輯。
4. 客戶開通：已付客戶、已開通、待開通、有效登入與最近開通狀態。
5. 系統串接：金流、Email、LINE、公開 HTTPS 等服務健康度。
6. 安全稽核：安全事件、封鎖 IP、管理操作；測試事件收進進階工具。

桌面與手機都採單一工作區切換；一次只顯示一個主要區域，避免長頁混雜。網址雜湊保留，因此重整後仍會回到相同區域。

## 視覺方向

- 定位為「仙閣司務台」：深靛紫側欄、暖紙色工作區、青玉正常狀態、月金提醒、朱砂風險。
- 裝飾只服務階層，不妨礙閱讀；日常資料使用清晰系統字，標題保留品牌書卷氣。
- 首頁加入清楚的「今日需要處理」區塊，取代一排同權重技術資訊。
- 所有原始英文狀態轉成消費與營運用中文；技術細節在需要時才展開。

## 互動與狀態

- 側欄切換工作區，支援鍵盤與 `aria-current`。
- 訂單支援全部、待付款、已付款、已取消／退款篩選，以及訂單、客戶、Email 搜尋。
- 快速待辦可直接跳至對應工作區。
- 載入、空資料、失敗與儲存成功皆有明確中文回饋。
- 手機版保留官網預覽與安全登出，不再把它們隱藏。

## 資料與隱私

- 後台 API 只回傳遮罩後 Email，不新增明碼個資輸出。
- 客戶開通只顯示營運狀態與統計，不輸出開通碼、登入碼、Token 或密碼。
- 官網不新增後台連結；既有後台仍須登入與 CSRF 驗證。

## 驗收

- 後台 API 與既有寫入操作測試全數通過。
- 新增客戶開通統計測試與後台結構測試。
- 桌面、平板、手機檢查：無水平溢位、側欄可操作、表格可讀、對話框可用。
- 瀏覽器主控台無錯誤；登入、切頁、篩選、編輯、登出皆可操作。
