# V14 封面題字與全站層級收斂

日期：2026-08-23

## 問題

上一版把白玉／月金立體效果套在幾乎所有 H1、H2 與卡片標題上，造成每一區都像主視覺、字級與陰影互相競爭；導覽列仍以 48px 小圖示搭配一般網頁字，品牌存在感不足，也未真正貼近使用者指定的仙俠小說封面參考。

## V14 決策

全站只保留四個視覺層級：

1. 品牌層：72px 圓形法筆印＋專屬「天外一筆」透明立體題字。
2. 主視覺層：首頁「一筆開天／靈感成案」與傳音頁「一筆啟月門／一念渡靈音」使用專屬插畫題字。
3. 區段／頁面層：所有可變動 H1、H2 收斂為同一套清楚月金標題，不再使用七層立體陰影。
4. 卡片層：H3 採單層淡金書法字，與主標明確拉開。

專屬題字保留可讀的 HTML heading 與替代文字；動態商品名、價格與營運內容仍使用真實文字，避免搜尋、無障礙與後台編輯能力退化。

## 資產

- `static/brand/wordmark-xianxia-v14.webp`
- `static/brand/home-title-xianxia-v14.webp`
- `static/brand/transmission-title-xianxia-v14.webp`

三張圖均採 WebP；總量約 1.3 MB。透明題字保留 alpha，首頁深藍底版本以 CSS luminance mask 只呈現題字筆畫，使其融入現有九霄背景。

## 驗收標準

- 桌機導覽列品牌組合不再像小 favicon，圓形法印為 72px。
- 首頁與傳音頁主標具有仙俠封面級筆勢，且文字內容正確。
- 同一畫面不再同時出現多組相同重量的立體大標。
- 其他 H2、H3 維持可讀、可縮放、可編輯。
- 三張 WebP 皆小於 650 KB。
- 公開頁保留正確 H1／H2 語意與替代文字。
