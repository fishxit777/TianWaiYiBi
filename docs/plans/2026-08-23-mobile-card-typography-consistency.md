# 手機版六脈卡片字型一致性修正

日期：2026-08-23

## 問題

首頁六脈卡片的角色名、主標與技能分類由資料庫種子動態帶入，但 Web Font 子集腳本沒有掃描 `tianwai/db.py`。手機瀏覽器遇到字型檔不存在的漢字時，會逐字改用系統楷體，造成同一個「商機觀星盤」內同時出現粗毛筆字與細楷書。

## 方案比較

1. 全部改用系統字型：不再缺字，但失去已確認的修仙書法品牌感。
2. 把六個主標做成圖片：外觀可控，但不利 SEO、無障礙、後台改名與響應式排版。
3. 修正自架字型子集來源並保留文字排版：把所有公開模板、公開文案程式與六脈資料納入字元蒐集，再重新產生 Regular／Bold WOFF2。此方案兼顧一致性、清晰度與維護性，採用。

## 字體層級

- 角色名：同一套 Regular 書法字體，較小尺寸、角色色與明確字距。
- 卡片主標：同一套 Bold 書法字體，不容許單字回退；手機維持 28px 以上。
- 技能分類：同一套 Regular 書法字體，以青玉色區分資訊層級。
- 六張卡片共用完全相同的規則，不針對單一卡片做特例。

## 防回歸

- 字型建置腳本掃描全部公開模板、公開 JavaScript 與公開端 Python 文案來源。
- 自動測試確認六脈的角色名、主標、技能分類都已進入字元蒐集集合。
- 手機寬度驗證六張卡片主標的 computed font-family、字級與水平溢位。
