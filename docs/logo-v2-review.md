# 天外一筆工作室 Logo V2 審稿

狀態：本機評估中，未上傳、未部署、未替換官網正式識別。

## V1 的十個業餘問題

1. 筆、劍、靈火、星軌與星芒同時搶主角，沒有單一記憶中心。
2. 左側圖騰過重、右側字標過長，整體視覺重心失衡。
3. 書寫、修仙、宇宙與遊戲四種語彙混在一起，品牌定位不夠聚焦。
4. 火焰高光、漸層與平面書法並存，媒材語言不一致。
5. 星軌細線、節點與筆觸粗線的線寬差距過大，小尺寸容易破碎。
6. 超長橫式比例不利於 LINE 頭像、App 圖示、浮水印及社群縮圖。
7. 深藍字標在深色底的對比不足，必須依賴陰影才能勉強辨識。
8. 主標狂草、工作室細字與副標裝飾體缺少統一的字體秩序。
9. 金色星芒與左右分隔線具有常見素材套版感，降低原創質感。
10. 太多細節只在大圖成立，縮到 32–64 px 後辨識性與品牌一致性會消失。

## V2 的重構決策

- 只保留墨藍與朱砂兩色。
- 以破界天門、中央筆劍與朱砂「一筆」形成單一門派徽記。
- 用負空間與輪廓建立修仙感，不靠火焰、粒子或行星特效。
- 紅色橫筆同時代表「一」、劍氣與把靈感落地的關鍵動作。
- 移除金色節點、星芒、裝飾分隔線、漸層、光暈與 3D 質感。
- V2 現階段是米白底方向審稿圖；核准後才製作真正的 SVG 與透明 PNG 母版。

6. SVG 向量母版。
7. 透明 PNG 2048 px、1024 px、512 px、256 px。
8. LINE 頭像安全裁切版。
