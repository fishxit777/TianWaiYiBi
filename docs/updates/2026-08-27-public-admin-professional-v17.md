# 官網與後台 V17 專業化更新

日期：2026-08-27

## 範圍

本次不是重新開發，而是在既有 V16、卷二傳音、客戶權限與正式金流閉環之上，完成第二輪各 20 項專業化。完整問題清單與驗收門檻見 `docs/plans/2026-08-27-public-admin-professional-v17-design.md`。

## 官網成果

- 新增手機章節導覽、桌機緊湊導覽、目前章節標示與長頁閱讀進度。
- 將「已購取回」提升到主要導覽，已購客戶不必翻到頁尾。
- 首屏新增可用狀態；正式收款關閉時明確顯示「摘要開放」，不再以付款用語製造錯誤期待。
- 收款關閉時，首頁六張卡改為「先看摘要」，仙策詳情不顯示結帳連結，改由該策傳音入口承接。
- 新增「適合／不適合」快速判斷帶，降低錯誤客群與不合理期待。
- 六脈篩選改為可保存於網址；重整或返回仍保留條件。隱藏卡片同步移出鍵盤焦點，並提供空結果重設入口。
- 仙策卡合併重複標籤，加入摘要、交付清單與專屬傳音的交付提示。
- 仙策詳情新增麵包屑，頁尾信任文案會依真實付款狀態切換。

## 後台成果

- 修正手機底部導覽硬編六欄造成第七個「安全稽核」被裁掉；現在七個工作區都在單列內完整可見。
- 儀表板加入載入、成功、斷線三態；重新整理期間防連點，斷線時顯示中文說明與就地重試。
- 同步時間改成相對新鮮度；三張交易 KPI 可用滑鼠與鍵盤直接進入訂單工作區。
- 訂單搜尋加入清除按鈕、條件摘要與空結果重設；手機訂單表依優先級收斂欄位。
- 全站價格、仙策上下架、可信裝置撤銷、解除封鎖、安全測試與公開／隱藏傳音都使用站內確認視窗，說明影響後才執行。
- 仙策編輯器加入未儲存狀態與離開保護。
- 傳音回覆依公開／私密即時顯示可見範圍與資料風險，管理按鈕提升觸控尺寸與主次層級。
- 已完成的 NT$6 驗收工具降為可展開歷史區，不再占據日常營運主畫面。
- 安全事件預設只看重大／高風險，可切換全部；進階測試工具再加一層非日常操作警示。
