# 2026-09-13 V31 現代可實作概念圖文

## 校正原因

V30 的十二卷新增圖像錯把官網修仙品牌語言延伸到付費揭示內容，古裝人物、仙宮、法器與魔法效果無法協助製造、工程或軟體團隊理解結構與實作方向。V31 依擁有者回饋，改以第壹卷的現代產品照、剖面拆解與真實使用場景為共同基準。

## 實作

- 第貳至第拾參卷全部換用新的 V31 圖像；每卷各有產品／系統主視覺、結構／資料流拆解、實際使用場景，共 36 張獨立 1600×900 WebP。
- 現代場景涵蓋感測地板、車用方向盤、弱網邊緣閘道、智慧農業、受控網路接力、即時聲畫舞台、山區監測節點、微距檢測治具、密封盒聲學品管、家電收音檢測、水產運輸感測箱及安全操作訓練台。
- 圖像不含古裝、仙宮、法器、符咒、魔法、品牌、可誤認為量產承諾的數字或文字；修仙氛圍只保留在官網品牌外框、封印流程與導覽。
- 每卷新增三則專屬圖說，分別說明產品／系統方向、部件或資料流、實際驗證場景與該題限制。
- 揭示頁明示圖像不是可直接投產的 CAD、施工圖、認證文件，也不構成工程、安全、醫療、法規、專利或獲利保證。
- SQLite 與 PostgreSQL 皆新增三個非機密圖說欄位。種子流程只對帶有 V31 圖說的十二卷比較並更新六個視覺欄位；值相同時不寫入，不觸碰第壹卷、訂單、顧客、付款、開通或已購權限。
- 音樂視覺卷的實作範例同步由仙境、雲流與仙門改為光流、幾何地景、粒子與抽象場景。
- 新增 V31 手機樣式：長工程標題可安全換行，圖說提高可讀性，拆解圖在窄版維持單欄。
