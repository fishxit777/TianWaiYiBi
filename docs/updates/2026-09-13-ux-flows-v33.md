## 設計原則

- 使用既有明亮玉色與清晰繁體中文正黑體；交易、登入採平實語氣，裝飾不侵入輸入與錯誤訊息。
- 依 frontend-design 的版面層級與 Code 的可驗證步驟，做既有流程修整，不另造新平台或更換品牌設計。
- 大圖仍透過原本 `/library/assets/…` 逐次授權；未新增公開圖址、下載、離線快取、儲存或分析事件。
- 未改伺服器、授權、付款、通知、資料庫或防護政策；既有 CSRF 欄位、私人內容浮水印與風險說明保留。
- 本次不執行正式寄信、正式付款、退款或推播測試。

## 自我驗收

1. 流程與回饋：15 個新測試、6 個既有客戶流程測試及 28 個私人內容防護測試，合計 **49 passed / 7.38 秒**。新增 JS 行為測試涵蓋連按抑制、20 秒恢復、pageshow 復原與不搶占已被取消的送出事件。
2. UI 與互動：1280px 桌面、320px 登入與錯誤、390px 已購清單/讀圖已在隔離瀏覽器驗收。沒有橫向溢出；窄屏輸入高 53.6px、主要與關閉按鈕高 48px；錯誤焦點、大圖關閉/Esc 後焦點返回均通過。
3. 安全邊界：新增腳本無 API 呼叫或 storage；未登入的大圖 URL 仍回 404。正式站驗證由主代理整體執行。

共完成兩輪 UI 自我驗收。第一輪發現 320px 步驟標籤出現單字換行，以及舊高 specificity CSS 導致大圖關閉按鈕使用低對比金字與陰影；第二輪已精簡標籤並明確設定深玉色 `#275f54`、移除字陰影，再次量測與截圖通過。付款結果與開通採合成訂單，沒有向正式金流或郵件服務送出請求。測試 viewport 已復原。
