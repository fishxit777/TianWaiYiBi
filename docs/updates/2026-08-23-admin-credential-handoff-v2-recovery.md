# 管理員憑證交接 V2 修復記錄

日期：2026-08-23

## 發現的缺陷

V1 在擁有者確認保存後立即關閉視窗並以 Argon2id verifier 覆蓋剪貼簿。
若密碼管理器沒有確實保存新密碼，Render 已更新但擁有者無法再次取得真正登入密碼，
造成正式登入失敗風險。

## 修復

- 交接視窗在 verifier 複製後繼續保持開啟。
- Render 部署完成後可再次複製真正的 43 位登入密碼。
- 只有擁有者確認正式登入成功後，視窗才會清除剪貼簿與畫面並關閉。
- verifier 已交付時不會因 30 分鐘逾時自動銷毀明文，以避免鎖死。
- 關閉尚未驗收的視窗前顯示明確警告。
- 新增狀態機測試，禁止未複製 verifier 就宣告完成。

## 驗收標準

1. 新 verifier 已在 Render 保存並重新部署。
2. 同一交接視窗可重新複製真正登入密碼。
3. 新密碼能登入正式後台。
4. 後台顯示 Argon2id 憑證已啟用。
5. 清除 legacy `ADMIN_PASSWORD` 後再次部署仍可登入。
