# 2026-08-30 V26 客戶訊息功能退役

## 結果

本版依擁有者確認，不改六脈分類名稱「傳音脈」，但完整退役官網上的客戶留言、客服引導與 LINE 接手功能。公開站不再提供聊天、留言、客服、加好友或 QR 入口；公開 NT$199 收款維持安全關閉。

## 已移除

- 公開 `/transmission` 頁、導覽／頁尾／交易流程中的客服與私人 LINE 文案。
- 客戶 LINE webhook、好友加入、文字指令、Flex Carousel 與本機模擬器。
- 客戶 LINE QR、圓形頭像、傳音題字與相關審稿資產。
- 公開／私密留言 API、前端互動、後台留言審核／回覆與留言通知。
- `section_messages`、`line_events` 的新 schema、啟動 migration、索引與 SQLite→PostgreSQL 搬移。
- 留言專用 Turnstile action、分析事件與已無使用者的 CSS。

舊 `/transmission`、`/dev/line`、`/line/webhook` 與留言 API 均保留 404 回歸測試，避免後續誤將功能加回。

## 明確保留

- 「傳音脈」仍是六脈之一，只表示內容／創意／品牌／教育／文化類問題，不是訊息或客服功能。
- 管理員 LINE 仍負責每日 08:00、12:00、20:00 營運摘要及高／重大安全告警。
- 客戶交易 Email 仍負責付款、開通、登入與退款狀態，不提供對話串。
- 已購內容、付款、退款撤權、Passkey、復原碼、PostgreSQL、備份與需求雷達核心規則不變。
- 正式資料庫若已有歷史 `section_messages`／`line_events`，只凍結供既有備份與稽核；本版不執行 DROP、DELETE 或正式資料重建。
