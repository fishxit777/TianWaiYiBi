# 2026-08-30 V19 全站清晰字體回歸

## 結果

- Logo、導覽題字與既有品牌圖片維持原檔，不重新設計品牌識別。
- 除 Logo 圖像外，公開官網、盲策詳情、結帳、付款／開通、客戶登入、訂單協助、管理登入、安全設定與營運後台全部改用繁體中文正黑體系。
- 公開 HTML 不再預載 MasaFont Regular／Bold，避免訪客下載已不使用的書法字型。
- 首頁主標與章標改用正常粗體建立層級，不再用毛筆字形或模糊描邊。
- 公開頁正文基準為桌機 18px、手機 17px；導覽與操作 15px，補充資訊最低 12px。
- 後台正文與操作基準 14px；原本 8～11px 的日期、即時狀態、串接標籤、圖表刻度與補充說明提升到至少 12px。
- 手機輸入框保持 16px，避免 iOS 聚焦時自動放大。
- 復原碼與訂單碼保留等寬字，原因是需要精確辨識字元；它們不是品牌書法字。

## 實作

- 新增最後載入的 `static/v19.css`，以單一可讀性層覆蓋歷史 V15～V18 的書法字與過小字級。
- `templates/base.html`、管理後台、管理登入、管理復原與管理安全設定均載入同一 V19 規則。
- 舊 WOFF2 與授權檔暫存為歷史資產，但不再由公開頁預載或使用；若後續確認無歷史相容需求，可另案移除。
- 健康版本更新為 `readable-typography-v19`。
